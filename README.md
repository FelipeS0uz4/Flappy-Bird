Este projeto é um clone do clássico **Flappy Bird**, desenvolvido como um desafio técnico para treinar os fundamentos do desenvolvimento Web. O foco principal foi criar um jogo funcional utilizando apenas tecnologias nativas (Vanilla JS), sem frameworks externos.

---

## 🎓 Contexto do Desafio
Este projeto faz parte do treinamento de estudo do curso **Web Moderno** da **Cod3r Ensino**. O objetivo foi consolidar conceitos teóricos através da prática direta em um ambiente de desenvolvimento real.

---

## 🛠️ Tecnologias e Ferramentas
* **HTML5:** Estruturação semântica e containers dinâmicos.
* **CSS3:** Design responsivo, animações e implementação de **Dynamic Themes** (Dark/Light Mode).
* **Vanilla JavaScript:** Lógica de jogo, física, pontuação e manipulação do DOM.

---

## 🧠 Conceitos Aplicados
Durante o desenvolvimento deste desafio, foram exercitados os seguintes pilares:

* **Manipulação de DOM:** Criação dinâmica de elementos através de funções construtoras para otimizar o desempenho.
* **Lógica de Colisão:** Implementação de cálculos espaciais via API `getBoundingClientRect` para detectar sobreposição entre o pássaro e as barreiras.
* **Game Loop & Animação:** Gerenciamento de quadros por segundo (FPS) utilizando `setInterval`.
* **Encapsulamento:** Organização do código em módulos lógicos, facilitando a manutenção e leitura.
* **CSS Variables:** Gerenciamento de temas (Dark/White) através de pseudo-classes e atributos de dados (`data-theme`).

## 🎮 Como Jogar
1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
    ```
2.  **Abra o arquivo `index.html`** no seu navegador de preferência.
3.  **Comandos:** Pressione qualquer tecla para fazer o pássaro subir e ganhar pontos ao atravessar as barreiras!
4.  **Temas:** Utilize o botão de destaque no topo para alternar entre o modo claro e escuro.
