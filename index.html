Desafio Flappy Bird 🐦

Este projeto foi desenvolvido como um exercício prático do curso Web Moderno da Cod3r. O objetivo foi consolidar o conhecimento em JavaScript puro, focando na criação dinâmica de elementos e lógica de animação.

O que foi treinado:

  • Manipulação de DOM: Criação e posicionamento dinâmico de elementos (Barreiras, Passarinho e Pontuação).
  • Lógica de Colisão: Uso da API getBoundingClientRect para detectar sobreposição de elementos.
  • Game Loop: Controle de frames e animação constante utilizando setInterval.
  • Encapsulamento: Organização do código através de funções construtoras.
Curso: Desenvolvimento Web Moderno (Cod3r Ensino) & Felipe Souza Panichi
